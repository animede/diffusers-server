Edit: 画像編集

モデル切替時は別モデルの解放 → 再ロードが走るため、数十秒かかることがあります。

Lightning使用時(cfg=1.0)はネガティブプロンプトは効きません。

48GB専有では標準解像度(自動推定、1024²相当)でOOMする場合があります。逼迫時は 幅・高さに 640 を明示してください(実測: 39GB程度に収まることを確認済み)。

Tポーズ4ビュー: 1枚の画像から3D化用のTポーズ立ち絵を生成

両腕を水平に広げたTポーズ(手のひらを正面へ)の正面・背面・左前45度・右前45度を生成します。 image-3d のマルチビュー入力(Hunyuan3D-2mv)と rig-service の自動リグ/VRM化(Tポーズ前提)向け。 正面を最初に生成し、他のビューはその正面画像を参照して連鎖生成します(前後の造形を揃えるため)。 image-3d へ渡すのは正面・背面の2枚にしてください(45度ビューは参考出力で、 2mv の left/right スロットへ入れるとカメラ事前分布を誤らせます。Tポーズの真横90度ビューは 手前の腕がカメラを向いて破綻するため提供しません)。 入力は全身でも胸像でも可(写っていない部分はモデルが創作します)。

生成するビュー(チェックしたものだけ生成)

爪: 既定の「爪なし」では、後足の指の分離が保たれるように入力画像から毛色を 自動推定して色名をプロンプトへ入れます(相対表現では効かず具体的な色名が必要、という 実測に基づく)。
被写体タイプ: リアルな人形で「背面が動物になる」「手に肉球が付く」場合は 「人物・リアルな人形」を選んでください(自動は毛皮/肉球の語を一切使わない 中立プロンプトになります)。ぬいぐるみで毛皮・肉球をはっきり出したいときは 「動物・ぬいぐるみ」を選びます。
肉球: auto=入力画像の色を踏襲 / none=言及しない / 色名(例 pink)を書くとその色の肉球を描きます(色を書くと自動判定は動物になります)。

しっぽ形状は正面画像からは推定できません。未指定だとビューごとに別の形状が 創作されます(実測で ポンポン/なし/長い尻尾 にばらけました)。入力画像に しっぽが写っていない場合は必ず指定してください。参照画像で指定することもできますが、 顔や毛色まで参照画像側へ引きずられるため非推奨です。

脚が長くなる場合はここを指定してください。ポーズを変える際に モデルが体型を人型寄りにドリフトさせることがあり(肩ライン比の実測で 0.45→0.37まで伸びた)、体型を言語化するのが唯一効いた対処です (ぬいぐるみ・デフォルメ体型では指定推奨)。

しっぽ参照画像(非推奨・実験用)

rembg(isnet-general-use)で切り抜きます。白背景版はそのまま残るので、 切り抜きが不自然なときは白背景版を使えます。生成完了後にCPUで処理するため GPUの待ちは発生しません(1枚1秒前後)。image-3d は自前で背景除去するため 必須ではありません。

生成後の編集(何度でも適用できます)

色調整だけでなく汎用の修正に使えます(「帽子を外す」等)。各タイルの 「このビューを編集」で1枚だけ適用も可能で、1世代分だけ元に戻せます。 強い指示は毛色や造形も動かします(実測: 暖色化の指示で毛色が黄褐色へ寄り爪が復活)。 背景透過版があるビューは編集後に作り直します。

動画生成(LTX-2.3、動画+音声)

蒸留モデル(8steps・guidance_scale=1.0固定=CFGなし)。フレーム数は8n+1、幅・高さは32の倍数を指定してください。48GB専有環境では自動的にtransformerのgroup offloadが有効になり生成が遅くなります(DS_LTX2_OFFLOADで明示指定可)。長尺動画(10秒超〜最大361フレーム=15秒)は既定構成ではVRAM不足になるため、サーバを DS_LTX2_OFFLOAD=group DS_LTX2_TE_QUANT=nf4 で起動してください(実測: 15秒動画がピーク43GB・生成36秒で成功)。
